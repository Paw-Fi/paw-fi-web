# Troubleshooting Common Issues


## Expenses Are Missing
Make sure:
- the expense was saved successfully
- you are viewing the correct Space
- internet connectivity is stable during syncing


## Shared Balances Look Incorrect
Check whether:
- expenses were split properly
- duplicate expenses were entered
- all participants logged payments consistently


## Receipts Are Not Uploading
Try:
- checking file permissions
- using a stable internet connection
- uploading a smaller image size

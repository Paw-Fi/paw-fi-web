## How Categories Work in Moneko

Categories organize your transactions so you can see where your money goes.

In Moneko, categories are assigned automatically by AI.  
You don’t need to select one when logging an expense.

### **When you log a transaction**

1. Add an expense (text, voice, photo, or chat)  
2. Moneko assigns a category instantly

The transaction is saved and organized right away.

### **Change a category**

If the category is not correct:

1. Open the transaction  
2. Tap the category  
3. Select a new category

After updating, you’ll see a prompt:

**Update preference for similar transactions?**

* Tap **Yes** → Moneko will remember this rule  
* Tap **No** → Only this transaction is updated

### **How learning works**

When you confirm a preference:

* Similar transactions will use the same category  
* You won’t need to correct it again

Over time, your categories become more accurate automatically.

## **Custom Categories**

You can create your own categories to better match your spending.

Use this if you want to track specific types of expenses or organize things your way.

### **Open category settings**

1. Tap the top right three dots  
2. Go to **Settings**  
3. Scroll to **Categories**

### **What you can do**

From this page, you can:

* Turn default categories on or off  
* Create custom categories  
* Choose icons and styles

### **Create a custom category**

1. Tap **Create Category**  
2. Enter a name  
3. Choose an icon  
4. Tap **Save**

The category will now appear when editing transactions.

You don’t need to create many categories at the start.  
Use the defaults first.  
Add new ones when you need them.

\#\#\# Expected Result

The selected transaction uses the new category. If you choose \*\*Yes\*\*, Moneko also uses that preference for similar transactions in the future.

\#\# How Category Learning Works

Moneko learns from the preferences you confirm.

When you choose \*\*Yes\*\* on the prompt, similar transactions will use the same category going forward.

This means:

\- similar transactions are categorized more accurately

\- you do not need to correct the same type of transaction again

\- your categories improve automatically over time

\#\#\# Example

If you change a coffee shop transaction to a specific category and confirm the preference, similar transactions can use that category next time.

\#\#\# Best Practice

Choose \*\*Yes\*\* when you want Moneko to remember the rule for future similar transactions.

Choose \*\*No\*\* when the change only applies to one transaction.

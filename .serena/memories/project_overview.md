# Project Overview

**Moneko** is a comprehensive financial technology platform designed to make financial education and planning accessible and engaging through AI-powered features.

## Purpose & Vision
- **Mission**: Make financial education and planning accessible through AI-powered interactive experiences
- **Core Features**: AI chat assistance, personalized goal tracking, educational courses, financial calculators, and comprehensive dashboard tools
- **Target Users**: Individuals seeking financial literacy, budgeting help, and financial goal achievement

## Project Type
- **Monorepo Structure**: Frontend (React/TypeScript), Backend (Supabase), Database schema
- **Full-stack Financial Platform**: Complete ecosystem with authentication, payments, AI integration, and educational content
- **Production-ready**: Deployed application with real users, subscription system, and payment processing

## Key Value Propositions
1. **AI-Powered Financial Guidance**: Google Gemini integration for personalized advice
2. **Comprehensive Education**: Interactive courses, lessons, and gamified learning
3. **Goal Tracking**: Sophisticated goal creation, milestone tracking, and progress monitoring
4. **Financial Calculators**: Multiple specialized calculators for different financial scenarios
5. **Customizable Dashboard**: Drag-and-drop widget system for personalized financial overview
6. **Subscription Business Model**: Freemium approach with premium features

## Business Context
- **Revenue Model**: Subscription-based (Stripe integration)
- **User Authentication**: Supabase Auth with social login options
- **Data Architecture**: PostgreSQL with Row Level Security (RLS)
- **AI Integration**: Google Gemini for chat, content generation, and personalized insights
